# Loomwright bundled fonts

These WOFF2 files are self-hosted copies of the eight book-typeface families that were previously requested from Google Fonts: EB Garamond, Libre Baskerville, Lora, Merriweather, Crimson Text, Playfair Display, PT Serif, and Bitter. The bundle includes Latin and extended-Latin glyph subsets, regular/bold weights, and regular/italic styles where supplied by the source stylesheet.

The font binaries came from the Google Fonts CSS API and are subset files served from fonts.gstatic.com. Each family’s SIL Open Font License 1.1 notice is included under `licenses/`. Family-specific licenses and authorship information are also available from the [Google Fonts repository](https://github.com/google/fonts). Do not remove the license notices when redistributing this bundle.

`../fonts.css` references only these local font files; the live app no longer needs the Google Fonts network request.
